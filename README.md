# iGOT Smart Learning Assistant

An Android learning companion for understanding course material and reviewing quiz questions.

## Scope
- Helps learners read and understand question text.
- Explains concepts and suggests study guidance.
- Leaves answer selection and final submission to the learner.
- Does not automate taps, submit assessments, or bypass platform evaluation.

## Project status
Repository initialized. Android application source and build workflow are the next steps.

## Privacy and API keys
Never commit API keys, passwords, or personal credentials. Configure service credentials securely outside the source repository.
